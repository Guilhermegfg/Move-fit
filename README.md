# Move Fit — seu próximo nível começa aqui

Uma academia fictícia com atitude de marca real. Landing page criada pela GFGTech para demonstrar como design, conteúdo e uma jornada simples podem transformar interesse em conversas de matrícula.

## A experiência

- Identidade esportiva em preto, branco e verde-lima.
- Hero fotográfica, faixa animada e entradas suaves ao rolar.
- Musculação, funcional, bike indoor, dança e mobilidade.
- Três planos com condições claras e mensagens específicas no WhatsApp.
- Estrutura, professores, depoimentos ilustrativos e perguntas frequentes.
- Grade de aulas interativa por dia da semana.
- Google Maps do Setor Marista, Goiânia–GO.
- Layout responsivo, menu mobile, navegação por teclado e respeito à preferência de movimento reduzido.
- SEO básico com título, descrição, idioma, favicon e metadados sociais de texto.

## Como usar

Abra `index.html` no navegador. Não há instalação, build, banco de dados nem dependência de Node.js.

Para hospedar na Hostinger, envie `index.html`, `style.css`, `script.js`, `hero.jpg`, `structure.jpg` e `team.jpg` à pasta pública do domínio ou subdomínio escolhido. Preserve eventuais arquivos de outro site. O conteúdo desses arquivos também pode ser servido por qualquer hospedagem estática.

No GitHub Pages, selecione a branch `main` e a pasta `/ (root)` nas configurações de Pages, se disponível. O envio deste código ao repositório, por si só, não ativa uma hospedagem nem uma integração de deploy automático.

Fontes do Google Fonts e o mapa dependem de internet. As fotos são locais. Links de WhatsApp abrem uma conversa, sem enviar mensagens automaticamente; visitas e matrículas são combinadas com a equipe. O mapa mostra a região, pois não foi fornecido um endereço de rua.

## Demonstração

Marca, preços, equipe, avaliações e condições são fictícios. Fotografias de banco de imagens não representam uma unidade real. Substitua esses dados antes de usar este projeto para uma academia real. Não há cobrança online, cadastro ou confirmação automática de matrícula.
